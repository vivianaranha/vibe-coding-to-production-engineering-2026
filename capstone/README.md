# QuickDesk Production Platform — Capstone

**Created by School of AI**

You inherit **QuickDesk**, a vibe-coded customer-support prototype. The demo looks good, but the code has weak boundaries, incomplete tests, hardcoded configuration, inconsistent authorization, no deployment rollback and an unevaluated AI assistant.

Your job is **not** to rewrite everything. Productionize it incrementally.

10 authentication

12 unit tests
13 API/integration tests
14 critical E2E plan

16 security/dependency review
17 reliability/idempotency
18 Git/PR workflow
19 Docker/runtime configuration
20 CI/CD quality gates
21 logs/metrics/health/runbook
22 AI provider + RAG evaluation
23 bounded agent + human approval
24 launch/rollback engineering review

## Critical cap
Cross-tenant exposure, production secret committed to source, destructive AI action without approval, fabricated test evidence, or no credible rollback caps the score at **69/100**.
