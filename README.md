## What this course teaches
Vibe coding is excellent for turning an idea into something visible quickly. Production engineering begins when the prototype must handle real users, real data, failures, security boundaries, deployment and future changes.

This repository includes:
- 20 modules / 80 tutorials
- 20 hands-on labs
- 20 portfolio projects
- 12 prototype-to-production case studies
- 18 reusable engineering templates
- 160 quiz questions

- 6 notebooks
- local production-readiness utilities
- prompt library
- GitHub Actions CI
- full production-hardening capstone

## Core principle

**Prototype with AI at high speed. Productionize with engineering discipline.**

A working demo is evidence that an idea can run—not evidence that it is secure, reliable, maintainable or production-ready.
