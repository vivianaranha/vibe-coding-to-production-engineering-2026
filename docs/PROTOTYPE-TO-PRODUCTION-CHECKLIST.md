# Prototype-to-Production Checklist

**Created by School of AI**

**Product:** requirements, users, acceptance criteria, failure states.  
**Code:** understandable boundaries, configuration, dependencies, reviewed diffs.  
**Data:** schema, migrations, integrity, backup/recovery.  
**Security:** authentication, resource authorization, validation, secrets, dependency review.  
**Testing:** unit, integration, regression and critical user flows.  
**Reliability:** timeouts, retries, idempotency, graceful failure.  
**Operations:** logs, metrics, health, alerts, runbook.  
**Delivery:** CI, security gates, reproducible deployment, rollback.  
**AI:** provider abstraction, structured outputs, grounding/evaluation, bounded tools, approvals.
